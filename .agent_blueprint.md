# 1. USER INTENT & WORKFLOW GOAL
The user's goal is to utilize Z-CAM as a professional-grade CNC programming environment, moving from CAD geometry preparation into robust toolpath generation and simulation. The workflow mirrors industry-standard CAM software (specifically Mastercam). The user will first organize their imported or sketched geometry using a unified 4-tab Left Manager (Levels, Toolpaths, Planes, Solids). They will define raw material using a Stock Setup utility, configure cutting tools in the Tool Library, and program a highly parameterized 2D Contour toolpath (including multipasses, depth cuts, lead in/out, and linking parameters). Finally, the user will verify the program by simulating the material removal in a live, interactive 3D viewport, distinguishing rapid movements from feed cuts via standardized color coding.

# 2. DESIGN TOKENS & GEOMETRY INVARIANTS
- **App Branding:** Window title and top-level UI headers strictly set to "Z-CAM".
- **Layout Spacing:**
  - Top Ribbon Height: `120.0` logical pixels.
  - Left Manager Panel Width: `320.0` logical pixels (resizable, minimum `250.0`).
- **Toolpath Render Colors (Mastercam standard tokens):**
  - Rapid Moves (G0): Yellow `Color32::from_rgb(255, 255, 0)` or Red `Color32::from_rgb(255, 0, 0)`.
  - Feed Moves (G1/G2/G3): Cyan `Color32::from_rgb(0, 255, 255)` or Blue `Color32::from_rgb(0, 0, 255)`.
- **UI Colors:** Active tabs and selected rows use a subtle highlight `Color32::from_rgb(220, 235, 255)` (light theme) or `Color32::from_rgb(40, 60, 90)` (dark theme).
- **Stock Display:** Translucent red or grey bounds, e.g., `Color32::from_rgba_unmultiplied(200, 50, 50, 60)`.

# 3. TECHNICAL IMPLEMENTATION SPEC
- **Workspace Additions:**
  - Create new crate `crates/cam` with standard `Cargo.toml` and `src/lib.rs`. Add to workspace members in root `Cargo.toml`.
- **Application Shell & UI (`apps/cam-workspace/src/app.rs` & `crates/ui-egui/src/`):**
  - `apps/cam-workspace/src/main.rs`: Rename window title to "Z-CAM".
  - `crates/ui-egui/src/left_manager.rs` (New): Implement the 4-tab panel (`Levels`, `Toolpaths`, `Planes`, `Solids`) using `egui::TopBottomPanel` and `egui::CentralPanel` or `egui_dock`.
  - `crates/ui-egui/src/ribbon.rs`: Update to include `Home`, `Wireframe`, `Solids`, `Simulation` tabs.
- **State Management (`crates/cam/src/state.rs`):**
  - `CamState`: Holds `levels: Vec<Level>`, `active_level: usize`, `tool_library: ToolLibrary`, `stock: StockDef`, `operations: Vec<Operation>`.
  - `Level`: `{ id: usize, name: String, visible: bool, selectable: bool, entity_count: usize }`.
- **Tool Library (`crates/cam/src/tool.rs`):**
  - Structs: `CuttingTool` (type, diameter, corner_radius, flute_length, flutes), `ToolHolder`, `ToolAssembly`.
- **Stock Setup (`crates/cam/src/stock.rs`):**
  - Enum `StockDef { BoundingBox { extents: [f32; 6] }, Solid(EntityId) }`.
- **Toolpaths (`crates/cam/src/operations/contour2d.rs`):**
  - `Contour2DParams`: Struct capturing `chain: Vec<EntityId>`, `tool_id: usize`, `cut_params` (comp dir, stock to leave), `depth_cuts` (max rough, finish), `multipasses` (rough/finish count & spacing), `lead_in_out` (line length, arc radius/sweep), `linking` (clearance, retract, feed_plane, top_stock, depth - with enum `Mode { Absolute, Incremental }`).
- **Rendering (`crates/engine/src/view.rs` / `crates/ui-egui/src/viewport.rs`):**
  - Inject 3D lines from `CamState::operations` into the `wgpu` render pass. Add a 3D coordinate Gnomon overlay at `(0,0,0)`.
