## Phase 2: Pocket Dialog Implementation
Implement the interactive dialog that drives the pocketing parameters, strictly adhering to `ui_kit` primitives.

**Files to create/modify:**
1. `crates/ui-egui/src/dialogs_cam_pocket.rs` (New File)
   * **Action**: Create the `PocketDialog` struct to maintain local transient state (selected loops, selected tool, stepover expression, depths).
   * **UI Implementation**: 
     * Mount the layout inside `crate::ui_kit::Panel`. **Do not use raw `egui::Window` or `egui::Frame`** to ensure `cargo xtask ui-containers` passes.
     * Use `crate::ui_kit::choice_row` for tool selection.
     * Use `crate::ui_kit::expr_row` for stepover amount, stock to leave, and bottom height to natively handle hostile math inputs (e.g., `"10mm + 2"`).
   * **Engine Execution**: On form confirmation, validate references and call `app.run("cam.toolpath.pocket", params)` constructed as a JSON Value matching the schema in `crates/engine/src/schema/cam_toolpath_pocket.rs`.
2. `crates/ui-egui/src/lib.rs`
   * **Action**: Export the new module by adding `pub mod dialogs_cam_pocket;`.
3. `crates/ui-egui/src/dialogs_cam.rs`
   * **Action**: Import `dialogs_cam_pocket::PocketDialog`.
   * **Action**: Hook into the active command router. When `app.active_command() == "cam.toolpath.pocket"`, delegate rendering to the new `PocketDialog`.
