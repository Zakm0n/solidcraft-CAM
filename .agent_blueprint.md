# Z-CAM Agent Blueprint: 2.5D Drilling Operation

## Phase 1: Engine Schemas and Document Formats
Establish the data contract for the Drilling command and its persistent storage format in the design document.

**1. Create Command Schemas (`crates/engine/src/schema/cam_toolpath_drill.rs`)**
*   Define the JSON-serializable `CamToolpathDrillContract` schema with exact parameters:
    *   `tool_id`: UUID of the selected CAM tool.
    *   `hole_centers`: List of Exact Geometry vertex/point references (`Vec<String>`).
    *   `cycle_type`: Enum for drill cycle (`Standard`, `Peck`, `DeepHole`).
    *   `depth_reference`: Enum (`HoleBottom`, `ModelBottom`, `Absolute`).
    *   `clearance_height`: `f64`.
*   Define `CamToolpathDrillOutput` schema to return toolpath generation success metrics and cycle time estimates.
*   **Action:** Add `mod cam_toolpath_drill;` to `crates/engine/src/schema/mod.rs`.

**2. Add Persistent Doc Format (`crates/doc/src/format/pending/cam_drill_v1.rs`)**
*   Create a single new file in `crates/doc/src/format/pending/` to define the binary/JSON serialization for the document layer so it can be saved/loaded across sessions.
*   Ensure it implements the required `Serialize`/`Deserialize` traits compatible with the SolidCraft feature timeline.

## Phase 2: Core Command & Toolpath Execution
Implement the command logic that validates inputs, performs depth/peck calculations using exact geometry, and avoids the UI thread.

**1. Create Command Execution (`crates/engine/src/cmd/cam_toolpath_drill.rs`)**
*   Implement `CommandSpec` for `cam.toolpath.drill`.
    *   Assign `.id("cam.toolpath.drill")`.
    *   Define hostile parameter validation (e.g., return `BadParams` if `clearance_height` is below `depth_reference`).
*   Implement `fn run(session: &mut Session, params: &Value) -> Result<Value>`.
    *   Calculate the exact start and end points for the drill based on B-Rep faces/vertices (never use meshes for model decisions).
    *   Generate the toolpath lines (rapid to clearance, plunge to depth, retract).
*   **Action:** Add `mod cam_toolpath_drill;` to `crates/engine/src/cmd/mod.rs` in sorted order.

**2. Implement Unit Tests (`crates/engine/src/cmd/cam_toolpath_drill_tests.rs`)**
*   Write programmatic tests validating exact toolpath coordinate output.
*   Ensure the command fails gracefully with hostile inputs.
