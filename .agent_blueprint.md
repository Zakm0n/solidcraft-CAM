# 1. USER INTENT & WORKFLOW GOAL
Create a reusable interactive 3D "Dynamic Gnomon" widget for Z-CAM to visually and precisely position a local coordinate frame. Wire this widget directly into the CAM Coordinate System creation workflow so that users can interactively drag, rotate, and snap axes to B-rep geometry (Face->Z, Edge->X) or type exact values in an interactive dialog, committing the `cam.coordinate_system.create` command only upon confirmation.

# 2. SOLIDCRAFT LAYER COMPLIANCE
- **Create:** `crates/ui-egui/src/dynamic_gnomon.rs` (L5 UI widget handling viewport raycasting and triad rendering).
- **Modify:** `crates/ui-egui/src/lib.rs` (Register `dynamic_gnomon`).
- **Modify:** `crates/ui-egui/src/dialogs_cam.rs` (Implement interactive CS creation dialog using `ui_kit`).
- **Modify:** `crates/engine/src/cmd/cam_coordinate_system.rs` & `crates/engine/src/schema/cam_coordinate_system.rs` (Ensure schema expects exact `origin`, `z_axis`, `x_axis`, and computes `y_axis`).
- **Modify:** `assets/locales/pending/zcam.json` (English strings for CS dialog and gnomon alignment modes).

# 3. TECHNICAL IMPLEMENTATION SPEC

**A. Core Structs & Enums (`crates/ui-egui/src/dynamic_gnomon.rs`)**
- `enum GnomonHandle { None, Origin, Translate(Axis), Rotate(Axis) }`
- `enum GnomonAlignMode { Free, SnapOrigin, AlignZFace, AlignXEdge }`
- `struct DynamicGnomon`
  - Fields: `origin: Point3<f64>`, `x_axis: UnitVec3`, `z_axis: UnitVec3`, `active_handle: GnomonHandle`, `hovered_handle: GnomonHandle`, `align_mode: GnomonAlignMode`.
  - Methods:
    - `fn draw(&self, canvas: &mut Canvas, theme: &crate::theme::Tokens)`: Renders lines/spheres representing axes. Uses `theme.x_axis()`, `theme.y_axis()`, `theme.z_axis()` (or primary semantic colors mapped to X=Red, Y=Green, Z=Blue).
    - `fn interact(&mut self, view: &mut Viewport, input: &InputState)`: Handles 3D picking. Resolves dragging handles based on viewport camera rays. Handles B-Rep picking for geometric alignment (using `view.pick(...)`).

**B. Interactive CS Dialog (`crates/ui-egui/src/dialogs_cam.rs`)**
- `struct CoordinateSystemDialog`
  - Fields: `gnomon: DynamicGnomon`, `target_setup: Option<Id>`.
- **UI Render (`ui_kit` compliant):**
  - Use `ui_kit::Panel` or `ui_kit::Window`.
  - Geometry selection modes via `ui_kit::choice_row` ("Free", "Snap Origin", "Align Z to Face", "Align X to Edge").
  - Origin coordinate fields via `ui_kit::expr_row` for X, Y, Z.
  - Apply / Cancel actions via `ui_kit::Confirm`.
- **Command Dispatch:**
  - On confirm, compute `y_axis = z_axis.cross(x_axis).normalize()`.
  - Execute `cam.coordinate_system.create` with `{ "origin": [...], "x_axis": [...], "y_axis": [...], "z_axis": [...] }`.
