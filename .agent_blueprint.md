# 1. USER INTENT & WORKFLOW GOAL
Z-CAM is a fully integrated industrial CAM expansion for SolidCraft. The user switches to the Z-CAM workspace within the existing SolidCraft UI to define machining setups, configure tool libraries, and generate 2.5D/3D toolpaths (facing, contouring, pocketing). The intent is a seamless transition from part design to manufacturing, using the exact same B-rep geometry without external exports, resulting in standard G-code generation.
