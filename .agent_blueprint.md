# 1. USER INTENT & WORKFLOW GOAL
The Product Owner wants to ensure the application UI is correctly rendering after a recent infrastructure change (enabling screenshots). The goal of this milestone is simply to trigger the rendering pipeline, capture the current state of the UI (which appears to be a Mastercam-like CAD/CAM environment), and verify that the core layout and visual elements are present and uncorrupted. No new functional features are being requested; this is a diagnostic rendering pass to validate the test harness itself.

# 2. DESIGN TOKENS & GEOMETRY INVARIANTS
*   **Viewport Background:** Expecting a gradient or solid light grey/blue as standard in CAD environments.
*   **UI Panels:** Expecting standard Windows-style or Qt-style dockable panels on the left (Levels, Toolpaths) and a ribbon menu at the top.
*   **Coordinate System Indicator (Gnomon):** A visible X, Y, Z axis indicator should be present in the main viewport, typically near the bottom left or attached to the active plane.
*   **Scale Bar:** A visible scale indicator at the bottom right.

# 3. TECHNICAL IMPLEMENTATION SPEC
*   **Focus:** Ensure the rendering loop executes at least once and the frame buffer is successfully captured by the external screenshot utility.
*   **State:** No new state variables or structs are required. The existing application state should simply be rendered.
*   **UI Widgets:** The existing widget hierarchy (Ribbon, Levels panel, Toolpaths panel, Main 3D Viewport) must be drawn.

# 4. AUTONOMOUS MILESTONE PHASES

**Phase 1: Trigger Application Render Cycle**
*   Ensure the application main loop executes a full render pass.
*   Confirm that all UI components (docked panels, ribbon, status bar) and the 3D viewport canvas are drawn to the primary frame buffer.

**Phase 2: Screenshot Capture Validation**
*   Allow the external testing harness to capture the screen state.
*   The agent does not need to write screenshot code, but must ensure the application remains in a stable state long enough for the capture to occur after the render pass completes.
